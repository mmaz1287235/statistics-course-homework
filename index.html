Homework Assignments

Homework 1

From a Private Key to a Public Key

An interactive introduction to elliptic-curve scalar multiplication, using the small toy curve y² = x³ + 7 (mod 17).

The experiment illustrates how a private key determines a public point on the curve. It includes step-by-step calculations, a graphical representation and a statistical exploration of the resulting points.

The example is educational and does not generate real Ethereum keys.

Homework 2

From Wallet Seed to Ethereum Address

An interactive demonstration of how Ethereum wallets derive an address from a mnemonic phrase, using BIP-39, BIP-32, BIP-44, secp256k1, Keccak-256 and EIP-55.

The page explains the role of each cryptographic primitive and includes statistical experiments on hash functions, mnemonic entropy and checksum error detection.

The demonstration uses public test data only. It is not intended for managing real wallet secrets.

Homework 2A

Encryption, Cryptanalysis and Small Key Spaces

An interactive comparison of elliptic-curve encryption and the Caesar cipher, exploring how different key spaces affect the security of encrypted messages.

The experiments include statistical cryptanalysis using English letter frequencies, a chi-square ranking of Caesar cipher keys and an evaluation across 3,500 trials with different message lengths.

An additional experiment demonstrates private-key recovery on secp256k1 when the key space is deliberately restricted. The cryptographic scheme is educational and must not be used to protect real secrets.
